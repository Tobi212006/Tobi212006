## Coursework material

Computer-science revision sheets (for example, DCN and IKS) are study aids, not software projects. Keep them separate from application source and publish only when they are original, accurate, useful to others, and free of personal or third-party material.

## Publication rules

- Do not upload personal documents, permission letters, student records, private correspondence, credentials, customer data, or third-party coursework without permission.
- Do not publish duplicate versions of the same report. Prefer one final, checked version per project.
- Do not claim test cases passed unless they were run and results recorded.
- Replace mockups with actual app screenshots only after running the application.
